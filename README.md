# 🐾 DayDayQuiz - 每日心理測驗與社畜避難所

> 每天零點自動更新的趣味心理測驗、社畜上班避凶籤詩與匿名爛事樹洞。

👉 **線上體驗**：[https://daydayquiz.com/](https://daydayquiz.com/)

---

## ✨ 核心特色
- **每日自動出題**：透過 GitHub Actions 串接 Google Gemini API，每日自動生成主題與四大人格卡牌。
- **社畜上班運勢**：打卡前 1 秒抽籤，掌握今日宜忌與辦公室防雷生物。
- **匿名爛事樹洞**：即時留言同步（Supabase），支援「我也遇過 (+1)」共鳴排行。
- **社群裂變設計**：一鍵複製 Threads 格式爆款文案，支援結果卡片高解析度截圖匯出。

## 🛠️ 技術架構
- **Frontend**：HTML5, Tailwind CSS, html2canvas, Supabase JS
- **Automation**：GitHub Actions (Cron Schedule)
- **AI Core**：Google Generative AI (Gemini 1.5 Flash)
- **Database**：Supabase (PostgreSQL with RLS)
- **Analytics & Ads**：Google Analytics 4, Google AdSense
